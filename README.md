#checkers game

##using it
Play by selecting your piece and clicking on the tile you want to move to. This game doesn't have instruction on how to play chekers, so pastt knowledge or learning those skills reccommended. Jumping Is available. Kingship not included yet. Hard mode is **unavailable**.

##Code
The board Object controld the entirety of the game. The pieces and tiles instances are used in the game for checking whether a piece can be moved, moving a piece, deleting a piece, checking whether tile is in range. Partial code was used from Springboard for Final Project. If there are any other bugs, please make an issue
